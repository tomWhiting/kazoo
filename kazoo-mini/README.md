# kazoo-mini

Moog Minimoog inspired bass/lead synth — monophonic, ladder filter.

This crate is part of [kazoo](https://github.com/tomWhiting/kazoo), a studio of synthesizers in the terminal. It is published so that `kzoo`, the one kazoo command, can be installed from crates.io:

```sh
cargo install --locked kzoo
```

kazoo runs on macOS. Free software under the GNU Affero General Public License, version 3 or later.
